# R Results Narrative Generator

## Purpose

All R analysis scripts MUST generate a `Results.md` file that includes:
1. **Tables** summarizing key statistics
2. **Results Narrative (For Paper)** section with academic prose containing embedded numbers

## Required Output Structure

Every R analysis script must include a section that generates `Results.md` with:

```markdown
# [Analysis Name] Results

**Generated:** [timestamp]

---

## 1. [Section with Tables]
| Metric | Value |
|--------|-------|
| ... | {value_from_data} |

---

## X. Results Narrative (For Paper)

### [Subsection]
[Academic prose with {embedded_statistics} using glue()]

---

## Definitions (what each name in the paper counts)
| Name as the paper prints it | Definition in words | Source columns (printed by the code) | Who enters, by route |
|---|---|---|---|
| treated | received at least one session | {paste(tx_cols, collapse = ", ")} | {n_direct} via a session record, {n_other} via the intake form |

---

*Analysis generated by R script: [script_name].R*
```

**The Definitions section.** One row per group or derived variable the paper NAMES. The source
columns and the counts come from objects the code computed (glue), never typed. Someone who knows the
data reads it before submission: it answers "does each name mean what the code counts?" - the
question no number-matching audit asks. Keep "recorded, none" apart from "nothing recorded": a
catch-all column such as `X_None` is never a route into the group, and missing data is never "no X".
Origin: a manuscript named a group whose code also counted a catch-all "none" column among its
members; every number matched the code and the label was wrong.

## Implementation Pattern

### Step 1: Collect all statistics into variables

```r
# After running analyses, extract key values
alpha_val <- round(alpha_result$total$raw_alpha, 3)
n_total <- nrow(df_clean)
n_group1 <- sum(df$group == 1)
n_group2 <- sum(df$group == 2)
f_val <- round(anova_result$F[1], 2)
p_val <- anova_result$`Pr(>F)`[1]
p_fmt <- ifelse(p_val < .001, "< .001", as.character(round(p_val, 3)))
eta_sq <- round(effect_size$Eta2_partial[1], 3)
emm_g1 <- round(emmeans_df$emmean[1], 2)
emm_g2 <- round(emmeans_df$emmean[2], 2)
```

### Step 2: Create interpretation strings (for conditional text)

```r
# Effect size interpretation
eta_interp <- ifelse(eta_sq >= 0.14, "large",
                     ifelse(eta_sq >= 0.06, "medium", "small"))

# Alpha interpretation
alpha_interp <- ifelse(alpha_val >= 0.8, "good", "acceptable")

# Significance interpretation
sig_interp <- ifelse(p_val < .05, "significant", "not significant")
```

### Step 3: Build markdown with glue()

```r
pacman::p_load(glue)

md_narrative <- glue("
## Results Narrative (For Paper)

### Reliability

The [scale name] demonstrated {alpha_interp} internal consistency (Cronbach's alpha = {alpha_val}, N = {n_total}).

### Group Differences

A [analysis type] was conducted to examine differences between Group 1 (n = {n_group1}) and Group 2 (n = {n_group2}) on [DVs], controlling for [covariates]. The [effect] was {sig_interp} (F({df1}, {df2}) = {f_val}, p {p_fmt}, partial eta-squared = {eta_sq}).

Group 1 scored significantly [higher/lower] (EMM = {emm_g1}) compared to Group 2 (EMM = {emm_g2}), representing a {eta_interp} effect size.
")
```

### Step 4: Write to file

```r
writeLines(paste0(md_tables, md_narrative), file.path(output_dir, "Results.md"))
cat("Results.md generated successfully!\n")
```

## Academic Writing Style Guidelines

### For ANOVA/ANCOVA:
> A one-way ANCOVA was conducted to examine differences between [groups] on [DV], controlling for [covariates]. The main effect of [IV] was significant, F({df1}, {df2}) = {f_val}, p {p_fmt}, partial η² = {eta_sq}.

### For t-tests:
> An independent samples t-test revealed a significant difference between [Group 1] (M = {m1}, SD = {sd1}) and [Group 2] (M = {m2}, SD = {sd2}), t({df}) = {t_val}, p {p_fmt}, Cohen's d = {d_val}.

### For correlations:
> There was a significant [positive/negative] correlation between [X] and [Y], r({df}) = {r_val}, p {p_fmt}.

### For regression:
> The regression model was significant, F({df1}, {df2}) = {f_val}, p {p_fmt}, R² = {r_sq}. [Predictor] significantly predicted [DV], β = {beta}, t = {t_val}, p {p_fmt}.

### For reliability:
> The [scale] demonstrated [excellent/good/acceptable/questionable/poor] internal consistency (Cronbach's α = {alpha_val}).

## Effect Size Interpretation

| Statistic | Small | Medium | Large |
|-----------|-------|--------|-------|
| η² (partial) | .01 | .06 | .14 |
| Cohen's d | 0.2 | 0.5 | 0.8 |
| r | .10 | .30 | .50 |
| R² | .02 | .13 | .26 |

## Alpha Interpretation

| Range | Interpretation |
|-------|----------------|
| ≥ .90 | Excellent |
| .80-.89 | Good |
| .70-.79 | Acceptable |
| .60-.69 | Questionable |
| < .60 | Poor |

## Checklist

Before finishing any R analysis script, verify:

- [ ] `Results.md` is generated automatically
- [ ] All statistics use actual values from data (via `glue()`)
- [ ] Tables are included for quick reference
- [ ] Narrative section exists with academic prose
- [ ] Effect sizes are reported and interpreted
- [ ] p-values formatted correctly (< .001 vs actual value)
- [ ] Sample sizes included in narrative
- [ ] Text is copy-paste ready for paper
- [ ] A Definitions section names every group the paper names: definition, source columns printed by
      the code, counts by route; "recorded, none" kept apart from "nothing recorded"
