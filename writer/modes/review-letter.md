# Mode: Review Letter

Reviewer response letters for journal submissions.

**Trigger keywords**: "reviewer response", "revision letter", "response to reviewers", "תשובה לבודקים"

---

## What This Mode Does

Writes structured, professional responses to reviewer comments. Each response shows the reviewer that their concern was understood, taken seriously, and addressed specifically.

---

## Structure

### Header
```
Response to Reviewers
Manuscript ID: [ID]
Title: [Title]
```

### For Each Reviewer

Follow the reviewer's EXACT order and numbering. Never re-order or skip comments.

```
## Reviewer [N]

### Comment [N.1]: [Brief summary of the comment]

**Response**: [Your response]

**Changes made**: [What changed in the manuscript, with page/line numbers]
```

---

## Response Principles

### Match Reviewer's Numbering
Follow the reviewer's exact order. If they numbered 1-15, respond to 1-15 in that order. Never re-organize their comments by theme.

### Response Types

| Reviewer Comment | Response Pattern |
|-----------------|-----------------|
| Substantive criticism | Acknowledge validity → explain how addressed → cite specific changes |
| Request for clarification | Thank them → provide clarification → note where added in manuscript |
| Methodological concern | Acknowledge → explain rationale → additional analyses if needed → changes |
| Minor correction | "Thank you for catching this. Corrected on p. X, line Y." |
| Suggestion you disagree with | "We appreciate this suggestion. However, [reasoned explanation]. We have [what you did instead]." |

### Tone
- Professional, never defensive
- Grateful for substantive feedback
- Direct but respectful when disagreeing
- Show that each comment improved the manuscript

### Quoting Changes
- Include the actual new/revised text in the response letter
- Use page and line numbers
- For large changes, reference the section: "See revised Discussion, paragraphs 2-3"

---

## Revision Tracking

### In the Letter
- Bold or italicize new/changed text when quoting from the revised manuscript
- Use "Track changes are enabled in the revised manuscript" if applicable

### In the Manuscript
- All changes should be visible via track changes in the .docx
- Consider using the revision mode for implementing changes

---

## Critical Rules

- Follow reviewer's exact order/numbering
- NEVER remove content depth during revisions; preserve all substantive arguments
- Cohen's d and Hedges' g are different effect sizes; verify which is appropriate
- APA format for all academic outputs
